Algoritmo usado no treino será o Random Forest 
Captura natural de Thresholds, visto que de acordo com decisões prédeterminadas o modelo escolhe ir para um lado ou outro.
Cria vários tipos de combinações de árvore de decisão e aó final é escolhida a melhor arvore por votação, o que pode evitar overfitting.
O Random forest não se importa com escalas diferentes, é avaliado corte relativo.
Traz também a probabilidade de de chance de risco.
